# Нақты орындалған тексерулер

Тексерілген күн: 20.11.2026. Орта: Windows, Python 3.13.0, Streamlit 1.67.0, SQLite 3.45.3. Кітапханалар бөлек виртуалды ортаға орнатылды; `pip check` тәуелділіктерде қайшылық таппады. Орнатылған нұсқалар `requirements-lock.txt` файлында бар.

Қызмет қабатының тесттері 40.264 секундта, соңғы интерфейс тексерісі 29.919 секундта орындалды. Соңғы интерфейс тексерісінде ескерту шыққан жоқ. Бір бастапқы тексеруде CSV дайындауда pandas типтерін таңдау ескертуі табылып, түзетілгеннен кейін интерфейс тесттері қайта орындалды.

Қайталау командалары, жоба түбірінен:

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
python demo.py
```

## SQL және база

`demo.py` нақты орындалды: 5/5/5/5 бастапқы жазба, INSERT арқылы 8/6/12/10 нәтижесі, пациенттің мекенжайын және қабылдау уақытын UPDATE, қате қабылдауды DELETE, 17 SELECT және толық пациент картасы көрсетілді.

Жеткізілетін базаның негізгі кестелері: 8 пациент, 6 дәрігер, 12 қабылдау, 10 медициналық жазба. `PRAGMA integrity_check` — `ok`, `PRAGMA foreign_key_check` — 0 жол. Дәрігер жүктемесі 4/3/2/2/1/0; қабылдауы жоқ алтыншы дәрігер LEFT JOIN нәтижесінде сақталады.

## Тексеру шегі

`TEST_SCENARIOS.md` ішіндегі 30 сценарий — қолмен қайталау жоспары; олардың барлығы жеке-жеке қолмен орындалды деген тұжырым жасалмайды. Негізгі әрекеттер жоғарыдағы автоматты тесттермен қамтылды. Android, бұлтқа жариялау, үлкен жүктеме және өндірістік медициналық құпиялылық аудиті осы жергілікті курстық жобаның тексеруіне кірмейді.
