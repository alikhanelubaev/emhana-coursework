# Қолмен тексеру сценарийлері

Төмендегі сценарийлерді көшірме немесе оқу базасында орындаңыз. Әр сценарийде әкімшімен кіріңіз, егер басқа рөл көрсетілмесе.

| № | Әрекет | Күтілетін нәтиже |
|---|---|---|
| 1 | Жүйеге admin / Clinic2026 арқылы алғаш кіру | Басты бет ашылады, бастапқы көрсеткіштер 8/6/12/10 |
| 2 | Қате құпиясөз енгізу | Түсінікті қате, негізгі бөлімдер ашылмайды |
| 3 | Қате құпиясөзді бес рет енгізу | Бес минуттық кіру шектеуі базаға сақталады |
| 4 | Пациенттер → Қосу: жаңа аты-жөні, туған күні, жынысы, бірегей телефон, мекенжай | Сәтті хабарлама, нақты SQLite жолы пайда болады |
| 5 | Пациентті таңдап мекенжайын өзгерту | Тізім мен толық картада жаңа мекенжай көрінеді |
| 6 | Жаңадан жасалған, байланысы жоқ пациентті растау арқылы жою | Жол жойылады, басқа пациенттер сақталады |
| 7 | Қабылдауы бар Айдос Нұрлановты жою | База жоюды тоқтатады, қабылдаулары жоғалмайды |

| 13 | Медициналық жазбаға диагноз, шағым, ұсыныс қосу және өзгерту | Жазба пациент картасына түседі; өзгеріс сақталады |
